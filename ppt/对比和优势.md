# part 1 -竞争对手分析

这两个平台虽然都服务于B2B政企采购，但侧重点差异明显：**三横科技更侧重于“供应链+运营+AI技术”的一站式服务，强调商品交付能力；而阳光优采平台更侧重于“合规监管+寻源比价+区块链”，强调采购过程的合规性与权威性。**

以下是详细的对比分析：

------

### 一、 广州市三横信息科技有限公司（三横科技）

**核心定位：** 数智一体化供应链平台，强调以AI重构供应链，提供“技术+运营+货源”的全方位服务。

#### 1. 核心功能布局

- **“1+6”系统架构：** 拥有1大供应链中台，支撑6大核心板块（供应商管理、商品管理、库存管理、商城管理、客户管理、订单管理），能够实现与企业OA、财务、采购系统的API打通。
- **全场景覆盖：** 覆盖办公用品、工业品（MRO）、员工福利、定制化服务（如消杀、租赁）等四大场景。
- AI智能引擎：
  - **AI搜索：** 支持智能分词、同义词识别、多路召回，提升搜索精准度。
  - **智能比价：** 跨平台（京东、天猫等）抓取数据，进行多维度价格比对。
  - **智能风控：** 对供应商资质、违规上架、价格过高/过低进行检测。

#### 2. 独特特色与优势

- **“三商一体”服务模式：** 这是一个显著的差异化优势。三横不仅是**技术服务商**，还是**运营服务商**（全托管运营、活动策划）和**供应商**（自有仓储物流）。
- 强大的自有供应链与品牌：
  - **自有品牌：** 拥有“天色”（办公用品）和“天琪锐”（工业品）两大自有品牌。
  - **现货交付能力：** 拥有1000万+SKU，10000+平方米总部仓储，支持全国一件代发和24小时内发货。
- **精细化运营服务：** 提供全托管运营服务，包括商品规划、商城装修、营销活动策划（如中秋、年节专区）等，帮助客户减轻运营负担。

------

### 二、 阳光优采平台（国泰新点 & 中资数据）

**核心定位：** 比质比价阳光采购平台，强调“国家立信、央企用信”，专注于采购全流程的合规与监管。

#### 1. 核心功能布局

- **多元化采购方式：** 除了商城直购，还深度支持**询比采购、谈判采购、竞价采购**等多种合规采购模式，不仅是买东西，更是一个寻源交易系统。
- 灵析大模型AI赋能：
  - **供应商画像：** 基于行业大数据进行供应商信用认证和能力分析。
  - **智能检测：** 自动识别供应商资质造假、拆单规避招标、围标串标等风险。
- **区块链存证（阳光见证链）：** 这是其核心壁垒。采购全过程（比价报告、下单、履约、合规报告）实时上链，不可篡改，满足审计要求。

#### 2. 独特特色与优势

- **极强的央企/国资背景背书：** 由**中资数据**（国务院国资委组建的大数据平台）与**国泰新点**强强联合。拥有97家央企数据支持，符合国资委关于“阳光采购”的政策导向，权威性极高。
- **“一把尺”价格管控体系：** 创新推出了**合理价格区间**（设置上限防止资产流失，设置下限防止恶意低价竞争），不仅仅是比低价，而是比“合理价”。
- **严格的合规风控：** 平台自动生成“合规报告”并上链，领导审核时可看到“绿标合规”状态，极大降低了国企采购人员的决策风险和审计压力。
- **灵活的部署模式：** 提供SaaS化部署（免费接入、拎包入住）和本地化部署两种模式，适应不同规模企业的需求。

------

### 三、 竞对总结与差异化对比

| 维度         | **三横科技**                                 | **阳光优采平台 (国泰新点/中资数据)**                  |
| ------------ | -------------------------------------------- | ----------------------------------------------------- |
| **核心卖点** | **实物供应链能力** (有货、有仓、有品牌)      | **合规与风控能力** (有背景、有区块链、有数据)         |
| **解决痛点** | 解决“买不到、送得慢、没人运营”的问题         | 解决“不敢买、怕审计、怕担责”的问题                    |
| **AI应用点** | 侧重于**交易效率** (搜索、比价、商品治理)    | 侧重于**监管合规** (资质造假检测、拆单预警、信用画像) |
| **服务模式** | 技术+**全托管运营**+**自有货源**             | 技术平台+**数据服务**+**第三方货源聚合**              |
| **适用客户** | 对**交付服务体验**要求高，需要外包运营的政企 | 对**采购合规安全性**要求极高，面临严格审计的央国企    |

# part3 - 新功能列表

这是一个非常好的战略思考。通过对比**三横科技（全能型供应链服务商）\**和\**阳光优采（合规监管型平台）**，我们可以清晰地看到市场上的两种主流形态：一种是“我帮你做（运营+供货）”，另一种是“我帮你管（合规+风控）”。

您的项目**B2B托管交易商城**目前的定位非常独特，切入点是**“交易信任（资金托管）”**和**“用户体验（可视化+AI搜索）”**。

为了进一步增强竞争力，建议您从以下三个维度进行功能补强，既能吸收竞品的优点，又能放大自身的特色：

### 第一维度：吸收“阳光优采”的合规与风控能力（增强B端信任感）

阳光优采的核心壁垒是让国企领导“敢签字、免责”。您的平台虽然主打托管交易，但可以通过增加数据辅助功能来提升企业的采购安全感。

**建议添加的功能：**

1. **“价格合理性”红绿灯（对标阳光优采的“一把尺”）**
   - **竞品功能：** 阳光优采设置了“合理价格区间”，防止资产流失或恶意低价。
   - **您的改进：** 在您的商品详情页或下单页，利用AI增加一个**“市场价格标尺”**。基于该商品的历史成交价或全网比价，展示当前价格处于“低、中、高”哪个水位。
   - **价值：** 帮助采购员向老板证明“我买的不贵”，也帮助老板快速审批。
2. **交易全流程“时光轴”存证（对标阳光见证链）**
   - **竞品功能：** 阳光优采利用区块链技术，将下单、比价、履约全过程上链存证，不可篡改。
   - **您的改进：** 您已经有了“状态流转”，建议将其升级为**可视化存证报告**。在订单完成后，一键生成一份包含“谁申请、谁审批、何时付款、何时验收、资金何时解冻”的PDF电子回单，界面设计模仿区块链的节点风格。
   - **价值：** 虽然不用真的上区块链（成本高），但在视觉和流程上提供类似“审计底稿”的功能，对中大型企业极具吸引力。
3. **供应商/买家“信用画像”简报（对标灵析大模型）**
   - **竞品功能：** 阳光优采通过大模型分析供应商的履约能力和合规风险。
   - **您的改进：** 在您的“经办人工作台”或“卖家中心”中，增加一个**“交易信用分”**。基于您平台已有的“验收通过率”、“纠纷率”、“发货及时率”自动计算。
   - **价值：** 您的托管模式本身就是为了解决信任问题，量化的信用分能让好的供应商脱颖而出。

------

### 第二维度：借鉴“三横科技”的运营深度（提升复购与粘性）

三横科技不仅提供系统，还提供“全托管运营”和“场景化方案”，让客户省心。您的平台目前侧重交易工具，可以适当增加运营工具属性。

**建议添加的功能：**

1. **场景化采购清单（对标三横的场景化解决方案）**
   - **竞品功能：** 三横科技针对“办公、工业品、福利”提供精选商品池。
   - **您的改进：** 利用您的AI能力，开发**“一键采购清单”**功能。例如，客户输入“新办公室开荒”，AI自动生成包含清洁剂、垃圾桶、梯子等商品的组合清单，支持一键加入购物车。
   - **价值：** B2B采购往往是任务导向的，从“搜单品”升级为“买方案”，能大幅提升客单价。
2. **多平台比价与抓取（对标三横的智能比价）**
   - **竞品功能：** 三横科技支持跨平台（京东、天猫）抓取数据比价。
   - **您的改进：** 既然您的搜索已经很强，可以增加**“外部比价助手”**。允许采购方输入一个外部链接（如京东），系统自动在您的库中匹配同款或同参数的替代品，并计算差价。
   - **价值：** 直接证明您的平台更便宜或更具性价比，这是最硬核的转化工具。

------

### 第三维度：深化自身的“托管”与“AI”特色（构建差异化壁垒）

这是您区别于两大巨头的根本。他们做的是“流程”和“供应链”，您做的是“资金安全”和“极致体验”。

**建议添加的功能：**

1. **分阶段资金释放（里程碑支付）**
   - **现状：** 目前您的托管流程主要是“验收通过->全额结算”。
   - **升级：** 增加**“里程碑支付”**功能。例如：下单付30%定金（冻结） -> 发货付30% -> 验收付30% -> 质保期结束付10%。
   - **价值：** 这对于工业品、定制品或大额采购（您的目标场景）非常关键，比单纯的“一手交钱一手交货”更符合B2B复杂的商务条款。
2. **“经办人”角色的AI化（智能仲裁助手）**
   - **现状：** 经办人目前负责人工审核和仲裁。
   - **升级：** 引入**AI预审**。当买家发起“验收不通过”时，AI先分析买家上传的图片和描述，自动判定是否符合退款标准，给经办人提供“建议判决”。
   - **价值：** 降低经办人（即平台运营方）的人力成本，提高纠纷处理效率。
3. **可视化大屏的“老板模式”推送**
   - **现状：** 您已经有了很棒的ECharts看板。
   - **升级：** 增加**周报/月报自动推送**。每周五下午自动生成一张长图，通过微信/邮件发给老板，内容包括：本周省了多少钱（通过比价）、拦截了多少风险订单、资金流转效率如何。
   - **价值：** 让老板不仅在系统里看到价值，还能在手机里被动接收价值，增强客户粘性。
