## 💡 使用场景

### 场景1：日常数据监控 → **BI分析系统**
```
需求：查看今天的订单数据
操作：Dashboard → 数据分析 → 按时间 → 查看今日数据
```

### 场景2：分析卖家表现 → **BI分析系统**
```
需求：哪些卖家贡献最多？
操作：Dashboard → 数据分析 → 按卖家 → Top 20排行
```

### 场景3：交叉对比分析 → **BI分析系统**
```
需求：各状态在各月的分布情况？
操作：Dashboard → 交叉分析 → 行=状态, 列=时间 → 热力图
```

### 场景4：生成月度对账单 → **专业报表系统**
```
需求：给卖家发送对账单
操作：报表设计 → 选择"交易明细"模板 → 设置参数 → 导出Excel
```

### 场景5：打印存档 → **专业报表系统**
```
需求：生成纸质报表存档
操作：报表设计 → 预览 → 打印 → 盖章存档
```
