# B2B托管交易 BI报表系统

## 📊 功能概述

本系统为担保交易商城提供专业的BI报表和数据分析功能，支持多层级钻取和多维度交叉分析。

## 🎯 核心功能

### 1. Dashboard 监控看板 (`/report`)

**主要特性：**
- 📈 核心KPI指标实时展示
  - 监管资金总额
  - 今日流入/流出
  - 平均占用周期
  - 待处理业务
  - 风险预警
  
- 💰 资金池状态分布
  - 待确认收款
  - 已确认待发货
  - 已发货待验收
  - 待结算
  
- 📊 业务处理效率指标
  - 收款确认及时率
  - 纠纷处理满意度
  - 结算完成率

**交互：**
- 点击资金池卡片可直接跳转到对应业务页面
- 点击"数据分析"按钮进入钻取分析
- 点击"交叉分析"按钮进入多维分析

---

### 2. 数据分析钻取 (`/report/drill-down`)

**钻取层级：**
```
Dashboard（概览）
    ↓ 点击"数据分析"
维度选择页（按状态/时间/卖家/买家/金额）
    ↓ 点击图表柱状图
明细数据列表
    ↓ 点击"查看详情"
订单详情页
```

**支持的分析维度：**

1. **按状态分析**
   - 查看各个订单状态的交易金额和订单数
   - 柱状图展示，点击可筛选该状态的明细

2. **按时间分析**
   - 按月统计交易趋势
   - 折线图+柱状图组合展示
   - 分析业务增长情况

3. **按卖家分析**
   - Top 20 卖家交易排行
   - 识别核心供应商
   - 评估供应商贡献度

4. **按买家分析**
   - Top 20 买家采购排行
   - 识别重要客户
   - 客户价值分析

5. **按金额段分析**
   - 0-1千、1千-5千、5千-1万...
   - 了解订单金额分布
   - 优化产品定价策略

**数据筛选：**
- 日期范围筛选
- 订单状态筛选
- 金额范围筛选
- 关键词搜索（订单号/卖家/买家）

**数据导出：**
- 支持导出CSV格式
- 包含所有筛选后的明细数据

---

### 3. 多维交叉分析 (`/report/cross-analysis`)

**功能说明：**
- 类似Excel数据透视表
- 支持任意两个维度的交叉分析
- 热力图可视化展示

**使用方法：**

1. **选择主维度（行）**
   - 订单状态
   - 时间月份
   - 卖家
   - 金额段

2. **选择次维度（列）**
   - 与主维度不同的另一个维度

3. **查看结果**
   - 交叉数据透视表：精确数值展示
   - 热力图：直观颜色深浅表示金额大小
   - 行合计、列合计、总计

**典型应用场景：**

| 主维度 | 次维度 | 分析目的 |
|--------|--------|----------|
| 订单状态 | 时间月份 | 各状态订单的时间分布趋势 |
| 卖家 | 金额段 | 各卖家的订单金额结构 |
| 时间月份 | 金额段 | 每月大中小单的分布情况 |
| 订单状态 | 卖家 | 各卖家在不同状态的订单分布 |

**导出功能：**
- 导出完整的交叉表数据（CSV格式）
- 包含所有行列合计

## 🚀 使用流程

### 场景1：快速了解整体情况
```
访问 /report → 查看Dashboard → 关注KPI指标和资金分布
```

### 场景2：分析特定维度数据
```
访问 /report → 点击"数据分析" → 选择维度（如"按卖家"）
→ 查看柱状图排行 → 点击柱状图查看该卖家的所有订单明细
```

### 场景3：多维度对比分析
```
访问 /report → 点击"交叉分析" → 设置行维度="订单状态" 
→ 设置列维度="时间月份" → 查看热力图和交叉表
→ 发现"待结算"订单在某月激增 → 导出数据进一步分析
```

### 场景4：风险预警处理
```
访问 /report → 发现"风险预警"为红色（有预警项）
→ 点击"风险预警"卡片 → 跳转到待确认收款页面
→ 查看超时订单 → 进行处理
```
