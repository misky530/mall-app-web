# 专业报表系统 - 使用手册

## 📄 系统介绍

本系统是一个**类似FineReport/帆软**的专业报表设计平台，支持报表设计、预览、导出等功能。

## 🎯 核心功能

### 1. 报表管理中心 (`/report/management`)

**功能特性：**
- 📋 报表模板列表展示
- 🔍 搜索和筛选报表
- ➕ 新建报表模板
- ✏️ 编辑/设计报表
- 👁️ 预览报表效果
- 📋 复制报表模板
- 🗑️ 删除报表模板
- 📥 导出报表模板

**报表类型：**
- **明细报表（detail）**: 展示详细数据列表
- **汇总报表（summary）**: 按维度汇总统计
- **图表报表（chart）**: 图表 + 数据表组合
- **交叉报表（crosstab）**: 透视表形式

---

### 2. 报表设计器 (`/report/designer`)

**设计界面布局：**
```
┌─────────────────────────────────────────────────────┐
│  工具栏: 保存 | 预览 | 导出Excel/PDF | 打印        │
├──────┬────────────────────────────────┬─────────────┤
│      │         报表画布 (A4)          │             │
│ 组件 │  ┌─────────────────────────┐  │   属性面板  │
│ 工具 │  │ 页眉                     │  │             │
│ 箱   │  ├─────────────────────────┤  │  ┌─────────┐│
│      │  │ 📝 标题                  │  │  │ 基本    ││
│ 📝标题│  ├─────────────────────────┤  │  ├─────────┤│
│ 🔍参数│  │ 🔍 查询参数              │  │  │ 数据源  ││
│ 📋表格│  ├─────────────────────────┤  │  ├─────────┤│
│ 📊图表│  │ 📋 数据表格              │  │  │ 样式    ││
│ ∑汇总 │  ├─────────────────────────┤  │  └─────────┘│
│ 📄文本│  │ ∑ 汇总统计               │  │             │
│ 🖼️图片│  ├─────────────────────────┤  │             │
│ ─线条 │  │ 页脚                     │  │             │
│      │  └─────────────────────────┘  │             │
└──────┴────────────────────────────────┴─────────────┘
```

**可拖拽组件：**
1. **标题组件** 📝
   - 设置标题文字
   - 调整字号、对齐方式
   
2. **参数组件** 🔍
   - 日期范围
   - 下拉选择
   - 文本输入
   
3. **表格组件** 📋
   - 定义列（字段、表头、宽度、对齐）
   - 设置分组
   - 显示小计/合计
   
4. **图表组件** 📊
   - 柱状图、折线图、饼图等
   
5. **汇总组件** ∑
   - 总笔数、总金额、平均值等

6. **文本/图片/线条**
   - 自定义内容

**设计步骤：**
```
1. 从左侧工具箱拖拽组件到画布
2. 点击组件进行选中
3. 在右侧属性面板配置属性
4. 调整组件顺序（上移/下移）
5. 保存报表模板
6. 预览效果
```

## 🚀 使用流程

### 场景1：创建新报表

```
1. 访问 /report → 点击"报表设计"按钮
2. 进入报表管理中心 → 点击"新建报表"
3. 进入报表设计器
4. 拖拽组件到画布：
   - 标题组件 → 设置"交易明细报表"
   - 参数组件 → 添加日期、状态筛选
   - 表格组件 → 定义列：订单号、买家、卖家、金额、状态、时间
   - 汇总组件 → 显示总笔数、总金额
5. 设置报表属性（纸张大小、页眉页脚）
6. 保存报表
7. 点击"预览"查看效果
```

### 场景2：使用现有模板

```
1. 访问 /report/management
2. 浏览报表模板列表
3. 找到"交易明细报表"
4. 点击"预览"按钮
5. 设置查询条件（日期、状态等）
6. 点击"查询"查看数据
7. 导出Excel或打印
```

### 场景3：复制并修改模板

```
1. 访问 /report/management
2. 找到要复制的报表
3. 点击"复制"按钮
4. 系统自动创建副本
5. 点击副本的"设计"按钮
6. 修改报表内容
7. 保存为新模板
```

## 🎨 设计技巧

### 1. 表格设计
- 合理设置列宽（按内容长度）
- 数值列右对齐，文本列左对齐
- 使用合计行突出显示关键数据
- 启用分组小计便于查看

### 2. 参数设计
- 必填参数标记*号
- 提供合理的默认值
- 参数名称清晰易懂
- 日期参数建议用范围选择

### 3. 布局设计
- 标题居中、字号加大
- 参数区域置于表格之上
- 汇总统计置于表格之下
- 预留页眉页脚空间

### 4. 样式设计
- 表头使用背景色区分
- 小计/合计行加粗显示
- 重要数据使用强调色
- 保持整体风格统一

## 🔧 技术实现

### 前端技术栈
- **Vue 3**: 组件化开发


## 💡 常见问题

**Q: 报表数据从哪里来？**
A: 当前使用Mock数据，实际系统中可配置数据源（SQL、API等）。

**Q: 可以自定义纸张大小吗？**
A: 默认支持A4，可在报表配置中修改。

**Q: 导出的Excel能否编辑？**
A: 可以，导出的是标准Excel格式(.xlsx)。

**Q: 支持多页报表吗？**
A: 支持，数据较多时会自动分页。

**Q: 能否嵌入图表？**
A: 支持，可在设计器中添加图表组件。

**Q: 如何分享报表模板？**
A: 使用"导出模板"功能，将JSON文件分享给其他人导入。

## 🌟 与BI分析的区别

| 功能 | 专业报表系统 | BI分析系统 |
|------|-------------|-----------|
| **用途** | 生成标准格式报表，打印存档 | 数据分析、可视化探索 |
| **形式** | 纸质报表形式（A4纸张） | Web交互式页面 |
| **设计** | 拖拽式报表设计器 | 预定义分析维度 |
| **导出** | Excel、PDF、打印 | CSV数据导出 |
| **典型场景** | 月报、年报、对账单 | 实时监控、趋势分析 |

**建议：**
- **报表系统**：用于生成正式的纸质报表，需要打印、盖章、存档
- **BI分析**：用于日常数据查看、趋势分析、决策支持
