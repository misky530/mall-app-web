# B2B担保交易功能演示指南

## 快速访问链接

### 买家端功能
- **我的订单**: http://localhost:8080/order/list
- **购物车**: http://localhost:8080/cart
- **订单确认**: http://localhost:8080/order/confirm
- **支付页面**: http://localhost:8080/order/pay/{订单ID}
- **订单验收**: http://localhost:8080/order/inspect/{订单ID}

### 卖家端功能
- **订单管理**: http://localhost:8080/seller/order/list
- **发货页面**: http://localhost:8080/seller/order/ship/{订单ID}

### 经办人端功能
- **财务审核**: http://localhost:8080/agent/payment/verify

## 演示流程

### 1. 买家端完整流程

#### 步骤1：下单
1. 访问首页，选择商品加入购物车
2. 进入购物车，选择商品，点击"去结算"
3. 在订单确认页面：
   - 选择收货地址
   - 填写发票信息（可选）
   - 填写订单备注（可选）
   - 点击"提交订单"

#### 步骤2：支付
1. 自动跳转到支付页面
2. 查看收款账户信息（账户名称、银行账号、开户银行等）
3. 上传付款凭证（图片或PDF）
4. 点击"我已付款，提交凭证"
5. 订单状态变为"待确认收款"

#### 步骤3：等待确认
- 订单状态：待确认收款
- 等待经办人确认收款

#### 步骤4：验收
1. 当订单状态变为"待验收"时
2. 点击"去验收"
3. 选择验收结果：
   - **验收通过**：订单进入待结算状态
   - **验收失败**：填写失败原因，上传问题照片/视频

### 2. 卖家端演示流程

#### 访问卖家中心
- 方式1：在页面顶部导航栏点击"卖家中心"
- 方式2：直接访问 http://localhost:8080/seller/order/list

#### 查看订单
1. 在订单管理页面可以看到不同状态的订单：
   - **待发货**：只有经办人确认收款后的订单才会显示
   - **已发货**：已填写物流信息的订单
   - **待结算**：买家验收通过后的订单
   - **已结算**：经办人已结算的订单

#### 发货操作
1. 在"待发货"列表中，找到需要发货的订单
2. 点击"去发货"按钮
3. 填写发货信息：
   - 选择物流公司
   - 输入物流单号
   - 填写发货备注（可选）
4. 点击"确认发货"
5. 订单状态变为"已发货"，买家可以验收

### 3. 经办人端演示流程

#### 访问经办人页面
- 方式1：在页面顶部导航栏点击"经办人"
- 方式2：直接访问 http://localhost:8080/agent/payment/verify

#### 财务审核
1. 查看待确认收款的订单列表
2. 查看买家上传的付款凭证
3. 核对银行到账情况
4. 选择操作：
   - **确认到账**：订单进入待发货状态，通知卖家发货
   - **驳回**：填写驳回原因，订单回到待付款状态

## 订单状态说明

| 状态 | 说明 | 操作方 |
|------|------|--------|
| 待付款 | 买家已下单，未上传付款凭证 | 买家：上传凭证 |
| 待确认收款 | 买家已上传凭证，等待经办人确认 | 经办人：确认/驳回 |
| 待发货 | 经办人已确认收款，等待卖家发货 | 卖家：发货 |
| 待验收 | 卖家已发货，等待买家验收 | 买家：验收 |
| 待结算 | 买家验收通过，等待经办人结算 | 经办人：结算 |
| 已结算 | 经办人已结算，流程完成 | - |

## 注意事项

1. **演示数据**：所有数据都是Mock数据，存储在localStorage中
2. **状态流转**：订单状态需要按照流程顺序进行，不能跳跃
3. **权限控制**：实际项目中需要根据用户角色控制页面访问权限
4. **数据持久化**：刷新页面后，localStorage中的数据会保留

## 测试建议

1. **完整流程测试**：
   - 买家下单 → 上传凭证 → 经办人确认 → 卖家发货 → 买家验收 → 经办人结算

2. **异常流程测试**：
   - 经办人驳回凭证
   - 买家验收失败

3. **多订单测试**：
   - 创建多个订单，测试不同状态的订单显示

## 常见问题

**Q: 如何创建测试订单？**
A: 在购物车选择商品，点击结算，提交订单即可创建。

**Q: 卖家看不到待发货订单？**
A: 只有经办人确认收款后的订单才会出现在卖家的"待发货"列表中。

**Q: 如何模拟经办人确认收款？**
A: 访问经办人页面，在待确认收款列表中点击"确认到账"。

**Q: 数据会丢失吗？**
A: 数据存储在localStorage中，刷新页面不会丢失，但清除浏览器数据会丢失。
