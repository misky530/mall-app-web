# 🧪 搜索功能测试指南

## 快速测试流程

### 1. 启动开发服务器

```bash
cd /home/intel41/mall-app-web/mall-pc
npm run dev
```

### 2. 测试基础搜索

#### 测试1: 单关键字搜索
1. 打开浏览器访问 http://localhost:5173
2. 在顶部搜索框输入: `手机`
3. 按Enter或点击搜索按钮
4. **预期结果**: 显示所有包含"手机"的商品

#### 测试2: 多关键字搜索 (重点)
1. 搜索框输入: `华为 手机`
2. **预期结果**: 只显示同时包含"华为"和"手机"的商品
3. 搜索框输入: `小米 游戏 12GB`
4. **预期结果**: 只显示同时包含这三个关键词的商品

#### 测试3: 模糊匹配
1. 搜索框输入: `huawei`
2. **预期结果**: 能找到"华为"相关商品
3. 搜索框输入: `iphone`
4. **预期结果**: 能找到"iPhone"相关商品

### 3. 测试搜索历史

#### 测试4: 搜索历史保存
1. 依次搜索: `手机`, `笔记本`, `平板`
2. 点击搜索框（获得焦点）
3. **预期结果**: 显示搜索历史面板，包含刚才的3次搜索

#### 测试5: 点击历史快速搜索
1. 点击历史记录中的某一项
2. **预期结果**: 立即执行该搜索

#### 测试6: 删除单条历史
1. 鼠标悬停在历史记录上
2. 点击出现的删除图标
3. **预期结果**: 该条历史被删除

#### 测试7: 清除所有历史
1. 点击"清除历史"按钮
2. **预期结果**: 所有历史记录被清空

### 4. 测试热门搜索

#### 测试8: 热门搜索显示
1. 点击搜索框
2. **预期结果**: 显示热门搜索词（默认8个）

#### 测试9: 热门搜索统计
1. 多次搜索同一个词（如"华为手机"搜索5次）
2. 刷新页面后点击搜索框
3. **预期结果**: 该词出现在热门搜索中，且排名靠前

### 5. 测试混合搜索模式

#### 测试10: API可用时
1. 确保后端API正常运行
2. 搜索: `手机`
3. 打开浏览器控制台（F12）
4. **预期结果**: 控制台显示 "✅ 后端搜索成功"

#### 测试11: API不可用时
1. 停止后端API服务
2. 搜索: `手机`
3. 打开浏览器控制台
4. **预期结果**: 
   - 控制台显示 "⚠️ 后端搜索失败，切换到前端搜索"
   - 控制台显示 "🔍 使用前端 Fuse.js 搜索引擎"
   - 页面显示成功消息："🔍 使用智能搜索找到 XX 个结果"
   - 正常显示搜索结果

### 6. 测试搜索筛选

#### 测试12: 价格筛选
1. 搜索: `手机`
2. 点击价格区间: `1000-2000`

#### 测试13: 品牌筛选
1. 搜索: `手机`
2. 点击品牌: `华为`
3. **预期结果**: 只显示华为品牌的手机

### 7. 测试排序功能

#### 测试15: 相关度排序

## 🐛 常见问题调试

### 问题1: 搜索无结果

**检查步骤**:
1. 打开控制台，查看是否有错误
2. 检查是否成功初始化搜索引擎
3. 确认数据是否正确加载

**调试代码**:
```javascript
// 在浏览器控制台执行
import searchEngine from '@/utils/searchEngine'
console.log(searchEngine.rawData.length) // 应该 > 0
```

### 问题2: 搜索历史不保存

**检查步骤**:
1. F12 → Application → Local Storage
2. 查看是否有 `mall_search_history` 键
3. 检查浏览器是否禁用了LocalStorage

### 问题3: 热门搜索不更新

**检查步骤**:
1. 清除LocalStorage
2. 重新搜索多次
3. 刷新页面查看
