# BI报表模块 - 快速开始

## ✅ 已完成的功能

### 1. Dashboard 监控看板
- **路由：** `/report`
- **文件：** `mall-pc/src/views/Report/Index_v2.vue`
- **功能：**
  - 实时KPI指标展示
  - 资金池状态分布（可点击跳转业务页）
  - 业务处理效率指标
  - "数据分析"和"交叉分析"入口按钮

### 2. 数据分析钻取页
- **路由：** `/report/drill-down`
- **文件：** `mall-pc/src/views/Report/DrillDown.vue`
- **功能：**
  - 5种分析维度：按状态、时间、卖家、买家、金额
  - 可视化图表（柱状图/折线图）
  - 点击图表钻取到明细数据
  - 数据筛选器（日期、状态、金额、关键词）
  - 统计卡片展示
  - 明细数据表格
  - CSV数据导出

### 3. 多维交叉分析页
- **路由：** `/report/cross-analysis`
- **文件：** `mall-pc/src/views/Report/CrossAnalysis.vue`
- **功能：**
  - 任意两维度交叉分析
  - 热力图可视化
  - 交叉数据透视表
  - 行列合计
  - CSV导出

## 🎯 如何访问

### 方法1：通过导航菜单
```
登录系统 → 点击"报表中心" → 进入Dashboard
```

### 方法2：直接URL访问
```
http://your-domain/report              # Dashboard
http://your-domain/report/drill-down   # 数据分析
http://your-domain/report/cross-analysis # 交叉分析
```

### 方法3：从Dashboard进入
```
访问 /report → 点击"数据分析"按钮 → 进入钻取页
访问 /report → 点击"交叉分析"按钮 → 进入交叉分析
```

## 📊 使用示例

### 场景1：查看某个卖家的所有订单
```
1. 访问 /report/drill-down
2. 点击"按卖家"标签
3. 查看柱状图排行
4. 点击某个卖家的柱子 → 自动筛选该卖家
5. 在明细表格中查看所有订单
6. 点击"查看详情"进入订单详情页
```

### 场景2：分析各状态在各月的分布
```
1. 访问 /report/cross-analysis
2. 行维度选择"订单状态"
3. 列维度选择"时间月份"
4. 查看热力图和透视表
5. 发现某月某状态异常 → 导出数据进一步分析
```

### 场景3：快速处理待处理业务
```
1. 访问 /report (Dashboard)
2. 查看"待处理业务"卡片（黄色）
3. 点击卡片 → 跳转到 /agent 经办商工作台
4. 或点击资金池中的"待确认收款"卡片
5. 直接进入 /agent/pending-verify 处理页面
```

## 🛠️ 技术细节

### 数据来源
- 主要数据源：`/utils/reportData.js`
- 函数：`getAllB2BOrders()` - 获取所有B2B订单数据
- 支持前后端混合模式

### 图表库
- ECharts 6.0
- 响应式自适应
- 支持点击事件

### 样式
- 使用 Element Plus 组件
- 响应式布局（PC/平板/手机）
- 专业的商务风格

## 📝 注意事项

1. **权限要求**
   - 所有报表页面都需要登录（`requiresAuth: true`）
   - 建议设置为经办商角色可访问

2. **性能优化**
   - 大数据量时建议使用服务端分页
   - 图表数据限制Top 20（卖家/买家维度）

3. **浏览器兼容**
   - 推荐使用 Chrome、Firefox、Edge 最新版
   - Safari 需 14.0+
